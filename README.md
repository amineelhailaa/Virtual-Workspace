# WorkSphere / Virtual Workspace 

## Description du Projet
Virtual Workspace est une application web interactive permettant de gérer et visualiser en temps réel la position des employés dans un espace de travail virtuel.

##  Fonctionnalités Principales

### 1. Gestion du Personnel
* Ajout via formulaire
* Déplacement entre zones
* Suppression d’un agent
* Prévisualisation d'image
* Affichage des détails

### 2. Règles Métier & Validation
* Vérification des inputs (email, téléphone,...)
* Accès restreint selon le rôle
* Liste des agents autorisés par zone

### 3. Plan d’Étage Interactif
* 6 zones : Conference, Reception, Servers, Security, Personnel, Archive
* Ajout direct via icône  + 
* Positionnement visuel dynamique

### 4. Interface Moderne
* Basée sur tailwind
* Responsive

## Technologies Utilisées

### frontend
* HTML
* CSS / Tailwind
* JavaScript
